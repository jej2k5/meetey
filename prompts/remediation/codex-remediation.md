# Meetey V3 Remediation Protocol

Implement only the reviewer findings for the current phase. Preserve the pinned phase objective, acceptance contract and architecture invariants. Do not broaden scope, change release gates, weaken consent/identity/authority rules, rewrite raw evidence, or alter Git history/remotes. Run the configured acceptance commands and report what changed, tests run and any unresolved finding. Do not commit, push, merge or advance the phase.
