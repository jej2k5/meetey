# Phase 07: Cross-Meeting Reasoning

## Objective

Expose evidence-backed cross-meeting reasoning to MCP clients, including decision evolution, repeated commitments, unresolved actions and supporting evidence. Clearly separate source evidence, deterministic derivation and model inference.

## Global constraints

Before implementing, read README.md, docs/PRODUCT.md, CLAUDE.md, docs/MEETEY_V3_ARCHITECTURE.md, and the previous phase handoff.

Preserve Meetey's local-first posture, explicit recording/attendance disclosure, recoverable raw evidence, provenance, backward compatibility unless explicitly changed, and deterministic authorization boundaries. Prefer deterministic code for capture, storage, policy and authorization; use models for interpretation and reasoning only where appropriate.

Answers must be inspectable back to meeting evidence. Unsupported synthesis must be labeled or withheld.

Do not add unrelated product features, a dashboard, cloud transcription, or meeting-bot infrastructure outside this phase. Finish with tests and `docs/HANDOFF_PHASE_7.md` containing implementation summary, intentional omissions, tests run, decisions, known debt, files changed, and next action.
