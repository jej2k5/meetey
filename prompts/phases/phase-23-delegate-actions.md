# Phase 23: Delegate Actions

## Objective

Introduce governed action adapters for follow-ups, scheduling, tasks and future external systems. Every external action must pass independent action authority and produce an auditable result linked to meeting evidence.

## Global constraints

Read docs/MEETEY_V3_ARCHITECTURE.md and the previous handoff first. A participant request is not authorization. A spoken agreement cannot silently become permission to mutate an external system. Preserve access, disclosure and action separation and fail closed when authority is unknown.

Finish with tests and docs/HANDOFF_PHASE_23.md covering summary, omissions, tests, decisions, debt, files changed and next action.
